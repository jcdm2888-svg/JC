# Voice, Dialogue, Sound

## 配音指令 Required Fields

Every shot segment must include:

`配音指令：角色｜声源｜状态（身体/情绪/目标）｜语气特点（音量/语速/气息/尾音/情绪色彩）：对白或内心语言`

If no speech:

`配音指令：无｜无｜状态（无）｜语气特点（无）：无`

## Voice Constraints

- Do not change a character's source voice.
- Only adjust strength, speed, breath, resonance, tail sound, and emotional color.
- The same character must keep the same sound source across the text.

## Required Voice Detail

For speaking characters include:

- 咬字与节奏: 字头重不重, 字尾收不收, speed base.
- 气息与共鸣: chest/nasal, stable or unstable, breath habit.
- 口音/语体: ancient/modern/dialect tendency as source allows.
- 身体状态: stamina, injury, drunk, panting, suppressed voice.
- 情绪状态: calm, anxious, restrained anger, guilty, proud, near collapse.
- 目标: suppress, probe, comfort, redirect, command, hide, challenge.

## Long Dialogue Rule

If a line is too long for one shot, split visually across:

- speaker close-up for key words
- listener reaction if reaction is more important
- environment or prop insert
- supporting character or crowd reaction
- body movement that carries the sentence

Never change the original words.

## Sound

Sound is separate from picture. Describe only scene-valid sound:

- footsteps
- cloth movement
- weapon scrape
- breath
- fire
- wind
- impact
- spatial echo
- crowd murmur

No background music unless the user explicitly asks.
