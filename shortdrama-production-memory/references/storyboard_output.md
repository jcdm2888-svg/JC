# Storyboard Output Rules

## Page-Style Storyboard

When the user asks for the example-style storyboard table, do not output isolated single storyboard images unless asked.

Use long page images containing multiple horizontal shot cards. Each card should include:

- shot number and scene line
- storyboard preview image
- character position / camera / direction diagram
- characters
- action
- dialogue / narration
- emotion
- camera note
- visual / effects / props note

## Visual Style

- Use black-and-white or grayscale cinematic storyboard sketches unless the user requests full color.
- Keep image previews functional: composition, action, relation, spell/effect direction, and staging must be readable.
- No subtitles, shot numbers, dialogue text, or watermarks inside preview drawings unless the table layout requires labels outside the image.

## Position Diagram

Use simple overhead staging:

- `CAM`
- camera cone
- role dots
- motion arrows
- staggered positions
- screen direction and eyeline logic

## Final Delivery

If generating files, place only the requested final storyboard pages in the final folder. Keep temporary single frames out of the final delivery folder.
